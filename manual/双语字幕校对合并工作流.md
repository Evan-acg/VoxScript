# 双语字幕校对 + 合并为 ASS — 工作流指令

## 核心原则

**数据与代码分离：** 字幕文本是数据，格式转换是工具。工具写一次，永久复用。

## 输入

- 原文 SRT（`*-original.srt`）
- 译文 SRT（`*-translated.srt`）
- 工作目录应包含两个 SRT 文件
- 通用合并脚本 `merge_srt_to_ass.py`（同目录）

## 步骤

### 0. 原文翻译（可选）
无现成译文时，**直接输出完整的译文 SRT 文件** `*-translated.srt`，保持与原文一致的序号和时间戳：

```
1
00:00:06,316 --> 00:00:07,657
第一次的故事？

2
00:00:11,100 --> 00:00:13,722
没有爱也能做的就叫第一次对吧？
```

- **对话文本**：按语境自然翻译，匹配语气强度和感情色彩
- **感叹/语气词**：使用译文语言对应拟声词，整片保持一致性
- **俚语/隐语**：结合上下文理解后归化翻译
- **语法破碎条**：依据语境推断含义，合理补全
- 译文文本若以 `##注释` 开头，合并后自动使用 `注释` 样式（顶部居中）
- **长句时间轴拆分**：译文文本若超过屏幕宽度限制（中文 >40 字，英文 >70 字符），应将原条目拆分为多条，使每条字幕不超过宽度限制。英文按自然断句位置拆分（优先句号/逗号/空格），中文按对应比例位置切分并回退到最近标点。时间按文本长度比例分配，拆分后条目数取中英文所需分段数的较大值

### 1. 全自动校对
AI 一次性地逐条对比原文与译文，自动修正所有翻译问题：

- **明显误译**：词义错误、时态错误、代词错误（反身/宾格）、语态错误（主动/被动）、漏译/增译
- **措辞优化**：语气强度不匹配、感情色彩偏差（褒/贬）、自然度
- **错字/标点**：形近字混淆、全角/半角标点、多余空格、语法错误

### 2. 自动修正
AI 直接在译文 SRT 文件上修正问题文本行，一次性完成。无需分批人工审核，无需中间数据结构。

### 3. 合并为 ASS

```bash
python merge_srt_to_ass.py 01-original.srt 01-translated.srt
```

脚本自动：
- 按条目序号匹配原文和译文
- 译文以 `##注释` 开头 → 使用 `注释` 样式
- 其余条目 → `Default`（译文）+ `Original`（原文）底部双语
- 添加 `{\fad(120,120)}` 淡入淡出
- 转换时间戳格式

#### 样式表（精简版，只用 3 个）

```
[V4+ Styles]
Format: Name, Fontname, Fontsize, PrimaryColour, SecondaryColour, OutlineColour, BackColour, Bold, Italic, Underline, StrikeOut, ScaleX, ScaleY, Spacing, Angle, BorderStyle, Outline, Shadow, Alignment, MarginL, MarginR, MarginV, Encoding
Style: Default,Microsoft YaHei,11,&H00F2F2F2,&H0000FFFF,&H000F0F0F,&H80000000,0,0,0,0,100,100,0.6,0,1,1,1.2,2,20,20,5,134
Style: Original,Arial,12,&H00D7E3E8,&H0000FFFF,&H00222222,&H00000000,0,0,0,0,100,100,0.2,0,1,1,1,2,20,20,11,1
Style: 注释,微软雅黑,18,&H00FFFFFF,&HFF000000,&H00000000,&H00000000,0,0,0,0,100,100,0,0,1,0,0.5,8,0,0,5,1
```

#### 样式分配

| 用途 | 样式 | 位置 | 字体/大小/颜色 |
|------|------|------|---------------|
| 译文 | `Default` | 底部 Alignment=2 | Microsoft YaHei 11pt, 浅灰 #F2F2F2 |
| 原文 | `Original`（用 `{\rOriginal}` 切换） | 底部 Alignment=2 | Arial 12pt, 浅蓝 #D7E3E8 |
| 字幕组广告/注释 | `注释`（直接在 Style 列指定） | 顶部居中 Alignment=8 | 微软雅黑 18pt, 白色 #FFFFFF |

#### 时间戳转换
SRT `00:00:03,700` → ASS `0:00:03.70`

- 去掉小时的前导零
- 逗号改为点号
- 毫秒（3位）截断为厘秒（2位）
- `-->` 改为 `,` 分隔起止

#### 文本格式
- 多行文本：`\n` 替换为空格展平，确保每屏仅 2 行（译文 + 原文各一行）
- 若展平后仍超过宽度限制（中文 >40 字，英文 >70 字符），应在步骤 0 翻译时已完成拆分，不应存在此类条目
- 特殊字符转义：`{` → `\\{`，`}` → `\\}`，`\` → `\\\\`
- 全部条目加 `{\fad(120,120)}` 淡入淡出效果

#### 对话条目格式
```
Dialogue: 2,start,end,Default,,0,0,0,,{\fad(120,120)}译文文本\N{\rOriginal}原文文本
```

#### 广告/注释条目格式
译文文本以 `##注释` 开头时自动使用：
```
Dialogue: 2,start,end,注释,,0,0,0,,{\fad(120,120)}声明内容
```

### 4. 广告内容分离
以下内容的译文文本应加 `##注释` 前缀，合并后自动进入注释轨道：

- 字幕组片头/片尾声明
- 校对者水印
- 其他非剧情文本

### 5. 长句后处理拆分

合并后若验证发现仍有超限条目，用拆分脚本修正：

```bash
python split_ass_entries.py <双语.ass> <原文.srt> <译文.srt>
python merge_srt_to_ass.py <原文.srt> <译文.srt> <双语.ass>
```

脚本从双语 ASS 提取中英文，英文按自然断句拆分（≤70 字符），中文按比例位置回退到标点（≤40 字符），按文本长度重新分配时间。

## 验证标准

- [ ] 合并后条目数 = 原 SRT 条目数
- [ ] 每个对话条目都有 `\N{\rOriginal}` 切换原文
- [ ] 所有修改过的条目原文内容正确
- [ ] 样式表中只有 Default、Original、注释 三个样式
- [ ] 不修改原始 SRT 文件
- [ ] 译文 SRT 为独立文件，可脱离脚本单独编辑
- [ ] 每屏文本不超过 2 行（译文一行 + 原文一行）
- [ ] 单行不超出屏幕宽度（中文 ≤40 字，英文 ≤70 字符）。解析 ASS 文本字段时按 `Dialogue: layer,start,end,style,name,marginL,marginR,marginV,effect,text` 取第 10 字段，不可用 `split(',,')` 取索引 1
- [ ] 多行原文的 `\n` 已展平为空格

## 工具链

### merge_srt_to_ass.py

通用合并脚本，**不含任何字幕数据**。输入两个 SRT，输出一个 ASS。

```bash
python merge_srt_to_ass.py <原文.srt> <译文.srt> [输出.ass]
```

- 纯机械的格式转换
- 按序号匹配条目
- 自动识别 `##注释` 前缀
- 一次编写，跨项目复用

### split_ass_entries.py

从双语 ASS 提取原文和译文，拆分超长条目后输出两个 SRT。

```bash
python split_ass_entries.py <双语.ass> <原文.srt> <译文.srt>
```

英文按自然断句拆分（句号/逗号/空格），中文按比例切分并回退到最近标点。时间按文本长度比例分配，与 `merge_srt_to_ass.py` 配合使用。
